# DeepSeek 跨工作区 Session 导航

## 适用范围与产品行为

适用分支 `codex/app-specific-mappings`，接续 Build 277 的独立候选；不适用于正式版。启用 APP 自动匹配且 DeepSeek Harness 在前台时，未自定义、未显式禁用的左键/右键分别通过公开辅助功能界面选择上一个/下一个 Session。所有工作区按侧边栏顺序遍历，允许展开工作区和“其余会话”，空工作区跳过，首尾停住，不循环；按住不连续切换。成功确认选中目标后请求聚焦输入框。已保存的专属快捷键或显式禁用优先，不迁移、不改写配置。

只使用公开 NSWorkspace 与辅助功能 API。不读取第三方内部文件、数据库、私有协议或聊天正文。展开状态保留在 DeepSeek 界面中，不主动折回。搜索过滤未清空、选中状态不明确、界面不兼容、权限失效、切换 App/窗口、超时均停止本次请求，不猜测目标、不回退为方向键。并发请求忽略，失败后松开再按可重试。

## 准备

1. 保留正式版、Build 277 与现有偏好设置。手动退出旧测试版，打开本次独立包，确认构建号。只运行一个版本，不重装驱动或重置配置。
2. 确认测试版辅助功能已授权、自定义按键与 APP 自动匹配已开启。在 APP 适配页选择 DeepSeek，左右应显示“侧边栏导航”；已有自定义或禁用者先记录，未经用户同意不更改。
3. DeepSeek 安装并运行。准备至少两个工作区、多个 Session，包含空工作区、折叠工作区和“展开其余”列表；清空侧边栏搜索。准备可丢弃文字，避免发送真实内容。
4. 切 App 或操作鼠标前松开上下键：Build 277 按住滚动会持续拉回鼠标的问题保留为已知问题，本次不修复。

## 逐项实机验证

| 用例 | 操作 | 预期与失败判定 |
| --- | --- | --- |
| 首次右切 | DeepSeek 在前台、当前 Session 后有会话，单击右键并等待 | 只选择紧邻下一项，必要时展开工作区/其余会话；输入框出现光标。跳错、跳多项或没有聚焦为失败 |
| 反向返回 | 单击左键 | 回到前一 Session，光标在输入框，无新建、归档、置顶或 App 切换 |
| 工作区边界 | 从某工作区最后一项右切，再左切 | 跨到下一非空工作区第一项，再返回；空工作区跳过 |
| 隐藏列表 | 目标位于折叠工作区或“其余会话”内；另测收起整个侧边栏 | 自动展开后按完整顺序切换；侧边栏不可访问则安全停止，不能误点其他控件 |
| 首尾 | 全部列表第一项按左、最后一项按右 | 停在原 Session，不循环、不触发其他动作 |
| 长按/快速按 | 按住右键两秒后松开；随后逐次单击并等完成 | 按住只触发一次；忙碌期间忽略新请求，空闲后可再次切换 |
| 前后台/窗口 | 导航过程中用电脑切到其他 App 或 DeepSeek 另一个窗口 | 后续展开、选择、聚焦停止；其他 App 不收到动作，恢复前台后松开重按可恢复 |
| 搜索与不可用状态 | 搜索框有过滤文字；另测无选中、权限关闭或 DeepSeek 未运行 | 不清空搜索、不猜测、不误选、不申请新权限；条件恢复后重试 |
| 自定义优先 | 使用已保存的左右快捷键或显式禁用配置 | 仍遵守原配置；关闭自动匹配恢复基础方案 |
| 第一次语音 | 切 Session 后确认输入框光标，再按住语音说测试句并松开 | 首尾完整进入新 Session 输入框，不自动发送；旧 Session 不被写入 |

## 稳定回归

Codex 左右会话、主页单击聚焦/长按新建、菜单长按审查保持原行为；菜单双击双向切 App 并聚焦；两边首次语音、确定只发送一次、返回单击与连删、TV 单击 Tab/长按 Esc、上下滚动、音量、电源禁用均逐项回归。原来的菜单单击待处理会话、审批确认、审批 Esc 三项仍为待验证；DeepSeek 无可关闭场景时，Esc 关闭效果也保持待验证。

## 诊断与验证边界

通过测试版设置中的诊断入口收集日志，筛选 `SESSION NAV operation_id=` 并关联 `APP FOCUS`。日志仅含临时操作标识、方向、阶段和失败原因，不含 Session 标题、聊天内容或第三方路径。`selection_confirmed` 只代表公开选中状态已确认，`focus=requested focus_result=unknown` 需用户看光标确认；没有 `selected` 终态不能记成功。失败、超时或取消后记录动作顺序与前台类别，不附私人聊天。

自动化覆盖跨空工作区与首尾策略、展开确认、选择确认、超时、上下文失效、焦点回调门禁、配置优先级及不连发。只读现场探针已确认当前 DeepSeek `0.2.1-rc.2` 工作区提供 AXDisclosing/AXExpanded 和 AXPress；探针未展开或选择会话。自动化及只读探针不能证明真实按键、展开、切换、光标和首次语音，以上实机用例在新候选上均待用户验证。CLT 环境测试排除唯一依赖 XCTest 的 `SupplementalSettingsIntegrationTests.swift`，未启用可选硬件模拟依赖。

## DeepSeek 主页长按新建当前工作区 Session（后续候选）

仅新增默认主页长按动作；已有专属自定义快捷键或显式禁用优先，不改配置。单击仍聚焦，Codex 主页行为保持不变。先从唯一选中 Session 确认工作区，再通过公开“新建会话 → 选择工作区”流程选择同一工作区。只有该工作区出现新的选中 Session 才请求聚焦；新建 API 受理不是最终成功。工作区无法唯一确定、搜索过滤、切 App/窗口、权限失效或超时均停止，不猜测，不自动重试新建。若流程中断后留下空白页面，不自动发送、删除或替用户恢复旧会话。未发送的空白 Session 是否离开后保留，由 DeepSeek 自身决定。

| 用例 | 操作 | 预期与失败判定 |
| --- | --- | --- |
| 当前工作区 | DeepSeek 当前 Session 在非默认工作区，长按主页并松开 | 只进入同一工作区的一个空白 Session，输入框有光标；其他工作区新建、仍在旧 Session、无光标为失败 |
| 不连发 | 长按主页超过 2 秒，继续按住再松开 | 只新建一次，松开不补发单击、不切 App |
| 第二工作区 | 用左右键切到另一个工作区的已有 Session，再长按主页 | 归属随当前 Session 变化，不沿用上一次工作区 |
| 首次语音 | 新建后看见输入框光标，再按住语音说测试句并松开 | 首尾完整进入新输入框，不自动发送；旧 Session 无文字写入 |
| 单击回归 | DeepSeek 点开已有 Session，让输入框失焦，再单击主页 | 只聚焦，不新建 |
| 侧边栏收起 | 收起整个侧边栏后长按主页 | 自动打开侧边栏，确认当前工作区后仅新建一次 |
| 不明确状态 | 搜索有文字、没有选中 Session、权限失效，分别长按主页 | 不猜工作区，不重复创建；条件恢复后松开重按可恢复 |
| 中断 | 新建过程中切 App/窗口，等待后返回 | 后续操作停止，不抢回焦点、不向其他 App 发送动作；可能留下已打开的空白页须如实记录 |
| 保存覆盖 | 已有主页长按自定义/显式禁用，或关闭自动匹配 | 继续遵守原设置，不重写数据 |
| Codex 与其他键回归 | Codex 主页长按、DeepSeek 左右、菜单双击、返回/TV/语音等 | 与 Build 278 已测方案一致 |

自动化覆盖新建确认/错误工作区拒绝、超时不重试、捕获时切 App 取消、聚焦门禁、原自定义/禁用优先及完整主页按下/长按/松开不重复。代理已用公开 UI 手动验证工作区选择器流程，并只读确认选项是 AXMenuItem 且支持 AXPress；没有发送文字。生产适配器、新包遥控器、实际聚焦及首次语音仍待用户验收。

新动作沿用 `SESSION NAV` 日志，`direction=create scope=current_workspace` 标识请求，终态 `selection_confirmed` 表示该工作区出现新选中项；焦点和最终文字仍按原诊断边界由用户观察。失败原因包括 workspace_unavailable、creation_unavailable、creation_unconfirmed，忙碌时忽略新请求，不输出工作区名称或内容。
